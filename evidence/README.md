# External evidence manifests

Store one small JSON manifest per external artifact, conforming to [the manifest schema](../schemas/evidence-manifest.schema.json). Include an immutable version and SHA-256 of the exact bytes, a stable URI, access requirements, description, and rights/reuse notes. Do not include temporary signed URLs, credentials, personal data, or private account details. Link manifests from research notes. Validation checks metadata only; reviewers verify the artifact and access rights separately.
