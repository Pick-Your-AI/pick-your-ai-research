## Hands-on observation (retained; #66 owns further tests)

A browser request about private laptop inference returned Ollama, LM Studio, Jan, GPT4All, llama.cpp and Open WebUI with explanation cards. That verifies interaction, not every recommendation or privacy assertion.

A completed free Stack Builder test returned an ordered local PDF RAG workflow for Windows, 16 GB RAM and no GPU. It acknowledged memory/latency uncertainty and suggested reproducibility steps. The visible result named Docling, txtai, Chroma, Ollama, Gemma and Open WebUI. This verifies generated workflow advice, not that the combination runs, preserves privacy or produces an executable export.

Initial loading briefly displayed an exhausted allowance; after hydration one free request was available and used. No authentication or paid credits were required. The result discussed evaluation in prose but its six visible component steps did not specify an evaluation tool. It suggested both txtai and Chroma without a verified integration test; alternative-versus-joint storage roles need clarification. The same record is in [substitute-validation.md](../substitute-validation.md) (#66).

## Counterexample

- **Suffices (observed, one request):** a cost-sensitive user wanting a free, ordered toolchain for a common task (local PDF Q&A on a modest laptop) gets a credible component list with uncertainty in one request. Pick Your AI is redundant for "what free tools do I chain together?"
- **Falls short (observed gaps for that one request; hypothesis beyond it):** no evaluation step; overlapping storage components without integration evidence; no executable export, version pinning or runtime validation seen; scope limited to its free-tool catalog, so paid APIs, GPU hosting and cost totals are outside it.
