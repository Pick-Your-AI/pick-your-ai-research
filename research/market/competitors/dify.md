# Dify — desk-research profile

Status: draft for owner review. Operator: LangGenius. Classification: Adjacent competitor, Substitute workflow (analyst judgement).

## Workflow and competitive overlap
Users can compose applications directly, making visual workflow builders substitutes for a planning-only product.

## Technical evidence and limitations
Official docs describe workflows, knowledge and agent tools. Connector availability alone does not establish interoperable schemas, authentication or runtime quality across arbitrary combinations.

## Economics, access and rights
Its source license modifies Apache terms with multitenancy and frontend-branding conditions. Cloud plans and self-hosting have different commercial implications.

## Strategic implication and next test
Evaluate whether configuration advice saves work before building in Dify. Do not confuse drawing a workflow graph with proving component compatibility. #16/#25 own technical implications.
