# Research issue templates

Use [Market research deliverable](../../.github/ISSUE_TEMPLATE/market-research.yml) for a new independently reviewable question, [Market evidence validation](../../.github/ISSUE_TEMPLATE/market-validation.yml) for a material risk/claim test, and [the note template](../../templates/market-research-note.md) for evidence. The existing Research finding template remains appropriate for a small finding on an existing issue.

Templates request scope, deduplication, evidence, native parent, consumer, output path, criteria, owner, priority and next action. GitHub issue forms do not create native parents or Project fields automatically; the triager must attach and read back those after creation. Inbox/Triage is required until qualification is complete.
