# Support

For public questions, first search this repository’s issues and pull requests, then use the existing relevant issue or the repository’s issue intake. Follow CONTRIBUTING.md and provide a scoped question with sanitized evidence.

## Unresolved decisions

Use [the routing procedure](CONTRIBUTING.md#routing-decisions) for a decision that
needs another responsible role. Keep the original issue and accepted owner;
summarize the decision, prior disposition and next recipient without copying private
rosters or raw API data. The organization governance change
(Pick-Your-AI/.github#23) merged on 2026-10-30, but central routing still
requires an authorized recipient and a successful fresh private snapshot check.
The merge itself does not activate tooling, promise a response time or assign an
unaccepted owner.

Keep credentials, account details, personal/customer data and confidential reports
out of public issues. For sensitive security reports, follow [SECURITY.md](SECURITY.md); preserve
any more specific private support route above.
