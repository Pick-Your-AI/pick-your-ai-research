# Security policy

This repository holds research documents and datasets, not a deployed service. Please still report problems responsibly.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting: **Security tab > Report a vulnerability**. Please do not open a public issue for security-sensitive reports. If private reporting is unavailable, contact an organization owner through GitHub.

## What to report

- Credentials, tokens or personal data committed by mistake.
- Malicious or unsafe links or scripts in datasets or documentation.
- Vulnerabilities in tooling or workflows in this repository.

## Contributor guidance

Never commit secrets or personal data. Pin GitHub Actions to specific versions or commit SHAs, keep workflow permissions minimal, and review dependency updates before merging.
